# Personal Website

A personal website built with [Nuxt 3](https://nuxt.com) and [Nuxt UI](https://ui.nuxt.com), designed to be fast and aesthetic.

## Tech Stack

- **Framework**: Nuxt 3
- **UI Library**: Nuxt UI (Tailwind CSS)
- **Runtime & Package Manager**: Bun

## Setup

Make sure you have [Bun](https://bun.sh) installed.

Install the dependencies:

```bash
bun install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
bun run dev
```

## Production

Build the application for production:

```bash
bun run build
```

Locally preview production build:

```bash
bun run preview
```
